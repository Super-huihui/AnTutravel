# 云栖山三日团·友群 (45)

一个微信群聊。99 元云栖山三日游的团友群。

导游在发行程，团友在接龙，一切都很正常。

直到你开始往上翻聊天记录。

> ⚠️ **内容警告**：本页面包含突发惊吓（jump scare）、闪烁画面、恐怖音效与逐渐失控的内容。
> 心脏病、光敏性癫痫患者及易受惊吓者请勿体验。建议成年人在心理承受范围内游玩。

## 🎮 怎么玩

- **像翻群聊记录一样慢慢往下滑**。这不是一个网站，这是一个群。
- 你可以**真的在输入框里打字**——早期导游会正常回复你。后期……回复你的就不是导游了。
- 语音消息可以播放，也可以「转文字」。建议转文字。
- 红包可以拆。照片可以点开大图——**点开之后等一秒**。
- 位置共享可以打开。看看那个红点在干什么。
- 右上角 ⋯ 可以看群成员。注意谁「已退群」了，又是谁还在发消息。
- 🎧 戴耳机。首次点击后环境音自动响起（右上角可关）。
- 终幕全员禁言时按 **Esc** 可以退群（它会表示失望）。
- 它会记得你是第几次进群。

## 🔒 隐私说明

本页面**不会调用摄像头、不会收集或上传任何数据**。
所有"它知道你在干什么"的效果，都只来自你浏览器本地的时间、滚动位置和访问次数。
一切只发生在屏幕里。

## 🛠 技术

单文件、零依赖、可离线运行：

- HTML + CSS + 原生 JavaScript（`index.html`，约 60 KB）
- 完整群聊 UI：气泡 / 语音 / 红包 / 照片 / 位置 / 接龙 / 撤回 / 群公告 / 群成员 / 桌面端侧栏
- 滚动进度驱动的全局腐化：配色、噪点、文字、头像、状态栏电量与运营商
- Web Audio API 实时合成：消息提示音、语音杂音、引擎轰鸣、心跳、尖啸与气刹
- SVG 程序化绘制的纸人头像与「点开才发现不对」的照片
